# Licensed league marks

Genuinely official or licensed league logo files go here, named
`<league-slug>.svg` (or `.png` / `.webp`, 192 px or larger), with an optional
`<league-slug>-dark` file for dark themes. A file here takes the place of
supplied artwork and of TableTalk's own mark, with no other change
(`src/identity/assets.ts`).

Only add a file once written permission or another valid legal basis is in
place. The repository is public, so committing a file publishes it.

Empty on 28 Nov 2026. The custom artwork the site's owner supplied is in
`../../supplied/marks/` and is described in `../../supplied.ts`; it is not
official and does not belong here.
