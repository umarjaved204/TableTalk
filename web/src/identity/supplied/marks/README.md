# Supplied league artwork

Custom competition-inspired artwork, supplied by the site's owner: not
official, not licensed. What each file is, what was changed and how closely
it resembles the competition's own logo are in `../../supplied.ts`, and a
unit test keeps that list and these files in step.

Prepared on 28 Nov 2026: cropped to the mark, squared, 192 px WebP at
quality 80, within the supplied raster budget (`SUPPLIED_RASTER_BUDGET`).

**Private until cleared.** The image files here are ignored by git and never
committed: the repository is public, and this artwork has no legal basis for
publication yet. They are used when present on the owner's machine; a public
checkout (and CI) has none, so these clubs and leagues show TableTalk's own
SVG artwork instead. Keep the originals somewhere safe outside the repository.
