official, not licensed. What each file is, what was changed and how closely
it resembles the competition's own logo are in `../../supplied.ts`, and a
unit test keeps that list and these files in step.

Prepared on 28 Nov 2026: cropped to the mark, squared, 192 px WebP at
quality 80, within the supplied raster budget (`SUPPLIED_RASTER_BUDGET`).
